# Retired doctor-rescue concept

The earlier game randomly rescued the player with a doctor NPC. That mechanic was removed because an unpredictable rescue obscures the meaning of a failed run. The original doctor art remains preserved in `assets/images/npc/` with the user's existing changes, and it is excluded from the production build.

Do not add this NPC back as a random mechanical advantage. A future cosmetic cameo could fit the adult sitcom visual contract if it supports a deliberate new joke; see `docs/art-direction.md`.
